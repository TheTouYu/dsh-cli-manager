快捷键

      

        
          
/ 或 Ctrl+K聚焦搜索框（搜索范围：命令名 / 说明 / 命令文本 / 模块名）

          
↑ ↓ 或 j k选择上一条 / 下一条命令

          
Enter执行选中命令；危险级中/高会先弹出二次确认

          
c复制选中命令的「将要执行的 shell 命令」

          
Ctrl+Enter在参数输入框内直接执行当前命令

          
r重新加载 modules/*.json

          
?打开 / 关闭本帮助

          
Esc关闭弹窗；在搜索框内则清空并退出搜索

          
Tab在参数输入框、按钮之间移动焦点
